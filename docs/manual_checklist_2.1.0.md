# Ручний чек-лист: SENTRY SWM-2, прошивка 2.1.0

Пристрій зараз на **2.1.0** (`ota_0`, self-check пройшов). Консоль: `python -m serial.tools.miniterm COM3 115200` (або будь-який термінал 115200 8N1). Перед початком: `login qa_swm Pass1234`.

**Як заповнювати.** Історичний manual-прогін зберігає `PASS` / `FAIL` / `BLOCKED`. У поточній матриці `AUTO (HIL)` означає, що перевірку перенесено в автоматичну фізичну стадію; `AUTO+MANUAL` означає, що UART-частина автоматизована, але фізичний результат лишається manual.

Три пункти з дослідницького тестування (`RES-01/02/04`) я вже закрив сам (знайшов `selftest`, `factory reset confirm`, відкритий пароль у `dev dump`, секрет `sudo` у boot-логу — усе в `bugs/Improvements.md`). Тут вони не повторюються.

## Група 4. Сонар HC-SR04

**Важливо:** пристрій не моніторить відстань у фоні сам по собі. Показання з'являються лише під час активного заміру — одноразового `distance` або безперервного `distance log <мс>`. Просто піднести руку без запущеного заміру — нічого не станеться, це не баг, так і задумано. Тому в пунктах 27–30 **спершу** запускаємо `distance log 200` (замір кожні 200 мс), а вже потім рухаємо об'єкт; `distance stop` — щоб зупинити.
