# Ручний чек-лист: SENTRY SWM-2, прошивка 2.3.0

Пристрій зараз на **2.3.0**. Консоль: `python -m serial.tools.miniterm COM3 115200`. Перед початком: `login qa_swm Pass1234`.

**Структура.** Частина A — нові фічі 2.3.0 (Guard, Alert center, K4), ще ніким не перевірені фізично. Частина B — коротка регресія: не всі 39 пунктів з 2.1.0 повторюємо один в один (логіку команд уже перевірила автоматизація — 177/180 збіглось), а цілеспрямовано дивимось на фізичні речі, де найбільша ймовірність розбіжності між версіями: відомий баг BUG-009 і кілька візуальних пунктів, яких автотест не бачить.

Історичний manual-прогін зберігає `PASS`/`FAIL`/`BLOCKED`. У поточній матриці `AUTO (HIL)` означає перенесену автоматичну перевірку; `AUTO+MANUAL` означає, що UART/stimulus автоматизовані, але фізичний результат або передумова лишаються manual.
