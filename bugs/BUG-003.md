# BUG-003 — `relay pulse 99` приймається, хоча мінімальний імпульс — 100 мс

| Поле | Значення |
|---|---|
| Версія, де знайдено | 2.1.0 |
| Відтворюється в 2.3.0 | **Так — не усунена.** `relay pulse 99` і далі виконується без `E603` на 2.3.0 |
| Severity | Minor (імпульс спрацьовує поза специфікацією; фізичний вплив на клапан потребує оцінки) |
| Priority | P3 (Low) |
| Вимога PRD | RL-3: `relay pulse <100-10000>`; «Поза діапазоном (у т.ч. менше 100) — `E603 pulse must be 100-10000 ms`» |
| Тип | Валідація вводу, межа діапазону |
| Відтворюваність | 3/3 |

## Передумови
- DUT 2.1.0, Wi-Fi підключено, `login` виконано, реле вимкнене.

## Кроки відтворення
1. Виконати `relay pulse 99`.
2. Спостерігати реле (клацання) і діод GPIO4.

## Очікуваний результат
`E603 pulse must be 100-10000 ms`, реле не перемикається.

## Фактичний результат
Помилки немає, реле спрацьовує на імпульс:

```text
TX: relay pulse 99
RX: I (17339) sentry: [VALVE] OPEN (pulse)
    I (17459) sentry: [VALVE] CLOSED (pulse end)
```

Тривалість за часовими мітками логу ~120 мс. Лічильник перемикань `cycles` при цьому теж змінюється.
