## Що знайдено і виправлено

- **Фікстура стенда:** `wifi_baseline` перед кожним тестом викликала `nmcli connection up` для вже активних профілів, а це перезапускає AP
  і розриває Wi-Fi плати (`W110 reason 7` через ~1 с після старту тесту). Тепер `ManagedAp.ensure_baseline` піднімає лише неактивні профілі.
- **TC-WF-12:** тест використовує звичайний `reboot` замість `reboot_dut`.
- **TC-OTA-25:** (а) після `W110` очікується `E002`; (б) `E411` або `E402`: код залежить від прапорця `internet` у `status`
  (`NO` → миттєвий `E411 no internet - OTA server unreachable`, `OK` → `E402` після тайм-ауту; OBS-06).
- **TC-OTA-23/31:** очікування зв'язку перед тестом, повтор `ota server default`, повтор збереження сервера при розриві.
- **Слабкі перевірки:** `E101` після `reconnect` більше не вважається успіхом (повтор до 3 разів, потрібен `connected to`);
  `E105` при старті сесії не ігнорується (очікування `internet: OK` до 40 с).
